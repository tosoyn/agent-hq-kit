# С нуля: Orca, агент и штаб за один вечер

Эта инструкция для человека, который раньше не работал с ИИ-агентами в терминале. Она ведёт по порядку: от пустой машины до штаба, в котором агент помнит прошлую работу и ведёт задачи. Остальные документы шаблона написаны для агента, этот единственный написан для вас.

Делать всё руками не придётся. Руками вы ставите три программы и входите в аккаунты, а дальше настройку берёт на себя агент. Шаги ниже расписаны для macOS, Windows и Linux; там, где системы расходятся, это сказано отдельно.

## Что получится в конце

У вас будет три вещи. **Orca** это приложение, в котором агенты работают на ваших глазах: у каждой задачи своя вкладка с терминалом и своя копия проекта, поэтому несколько агентов могут работать параллельно и не мешать друг другу. **Агент** это Claude Code или Codex, программа, которая читает и пишет код и выполняет команды по вашей просьбе. **Штаб** это ваш личный приватный репозиторий на GitHub, где лежат правила для агентов, задачи и уроки, плюс поиск по истории всех прошлых сессий.

## Шаг 1. Аккаунты

Понадобятся два аккаунта.

1. **GitHub.** Если его нет, зарегистрируйтесь на github.com. В нём будет жить ваш штаб и задачи.
2. **Подписка на агента.** Для Claude Code нужна подписка Claude Pro или Max на claude.ai (или ключ API Anthropic). Для Codex нужна подписка ChatGPT Plus или выше. Достаточно одного агента; начать проще с Claude Code, на нём шаблон проверялся больше всего.

## Шаг 2. Базовые программы

Агенту и штабу нужны пять программ: `git` (история версий), Python 3.10 или новее, Node.js 22 или новее, GitHub CLI `gh` и сам агент. Агент потом поставит недостающее и сам, но первые программы проще поставить руками.

**macOS.** Откройте приложение «Терминал». Сначала поставьте инструменты разработчика Apple, в них входит `git`:

```bash
xcode-select --install
```

Затем поставьте Homebrew, менеджер программ для Mac, по команде с сайта brew.sh, и через него остальное:

```bash
brew install python node gh
```

**Windows.** Откройте PowerShell и поставьте программы через встроенный менеджер `winget`:

```powershell
winget install Git.Git Python.Python.3.12 OpenJS.NodeJS.LTS GitHub.cli
```

После установки закройте и заново откройте PowerShell, иначе новые команды не найдутся.

**Linux.** Поставьте `git`, `python3`, `nodejs` и `gh` менеджером пакетов своего дистрибутива. Если Node.js в репозитории старше 22, возьмите его с nodejs.org или через `nvm`.

**Вход в GitHub.** На любой системе выполните:

```bash
gh auth login
```

Выберите GitHub.com, протокол HTTPS и вход через браузер. Проверка: `gh auth status` пишет «Logged in to github.com».

## Шаг 3. Агент

**Claude Code.** На macOS и Linux:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

На Windows в PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Затем наберите `claude`. При первом запуске он предложит войти: выберите вход подпиской Claude, подтвердите в браузере и вернитесь в терминал. Проверка: в окне Claude Code напишите «привет», он должен ответить. Выйти можно командой `/exit`.

**Codex**, если нужен он или оба агента сразу:

```bash
npm install -g @openai/codex
```

Наберите `codex` и войдите через аккаунт ChatGPT.

Если команды установки к моменту чтения изменились, точные лежат на docs.claude.com (раздел Claude Code) и в репозитории openai/codex.

## Шаг 4. Orca

**Установка.** Скачайте Orca с onorca.dev/download или со страницы релизов github.com/stablyai/orca:

- macOS: файл `.dmg` для Apple Silicon (M1 и новее) или для Intel; либо `brew install --cask stablyai/orca/orca`;
- Windows: `orca-windows-setup.exe`;
- Linux: AppImage, `.deb` или `.rpm`, на Arch пакет `stably-orca-bin` из AUR.

На macOS при первом открытии система может спросить, точно ли открыть приложение из интернета: ответьте «Открыть». На Windows SmartScreen может показать предупреждение: нажмите «Подробнее», затем «Выполнить в любом случае».

**Первый запуск.** Orca попросит доступ к домашней папке, разрешите: там будут лежать проекты. Она предложит импортировать настройки из `~/.claude` и `~/.codex`, соглашайтесь. После этого откроется пустой экран со списком репозиториев слева.

**Настройки, которые стоит сделать сразу.**

1. **Командная строка Orca.** Settings → General → Orca CLI, включите регистрацию команды. Через неё агенты сами создают задачи, открывают терминалы и передают работу друг другу. Проверка: в новом терминале команда `orca status --json` отвечает, что приложение запущено. На Linux команда называется `orca-ide`: голое `orca` там запускает экранного диктора GNOME, и компьютер начинает говорить вслух.
2. **Оболочка на Windows.** Settings → Terminal, оболочка по умолчанию PowerShell.
3. **Агент по умолчанию.** Когда вы создаёте задачу, Orca предлагает выбрать агента и запоминает выбор. Выберите Claude Code (или Codex) в первый раз, и дальше он будет подставляться сам.

## Шаг 5. Штаб: настройку делает агент

1. Скачайте шаблон в домашнюю папку:

   ```bash
   git clone https://github.com/tosoyn/agent-hq-kit.git ~/agent-hq-kit
   ```

   На Windows вместо `~` можно написать `$HOME`.

2. В Orca нажмите **Add Repo** в левой панели и выберите папку `agent-hq-kit`.
3. Откройте терминал этого репозитория и запустите в нём агента, например `claude`. Работайте здесь в основном каталоге, отдельная копия для настройки не нужна.
4. Claude Code в новой папке первым делом спрашивает, доверяете ли вы этому проекту. Ответьте «да». Пока этот вопрос висит на экране, всё набранное уходит в него, а не агенту.
5. Скажите агенту:

   > Прочитай SETUP.md и помоги мне всё настроить.

Дальше агент ведёт сам. Он посмотрит, что стоит на машине, и задаст несколько вопросов: где будет жить штаб (обычно `~/HQ`), как назвать ваш приватный репозиторий, каких агентов подключить, какие папки добавить в поиск. На каждый вопрос он даст рекомендацию; если не уверены, соглашайтесь с ней. Перед каждым из шести этапов он скажет, что изменится, и подождёт вашего «ок», а после этапа покажет проверку. Ваше участие сводится к ответам, «ок» и паролю там, где без вас нельзя.

Одно предупреждение, которое агент тоже повторит: история сессий попадает в поиск целиком. Пароли и ключи в чат агенту не вставляйте.

В конце агент отдаст сводку: что установлено, где лежит и что проверено. Когда штаб готов, добавьте в Orca и его: **Add Repo** → папка `~/HQ`. Папку `agent-hq-kit` после этого можно убрать из Orca, она больше не нужна.

## Шаг 6. Первая задача в своём проекте

1. **Add Repo** → папка вашего рабочего проекта.
2. Попросите агента в штабе подключить проект: «подключи проект `<путь>` к штабу». Он напишет файл правил проекта и добавит строку в реестр.
3. Чтобы начать задачу, нажмите **+** рядом с именем проекта в левой панели. Введите короткое имя задачи; основа обычно `origin/main`. Orca сделает отдельную копию проекта на своей ветке (это называется worktree) и откроет в ней терминал с агентом.
4. Опишите агенту задачу обычными словами. Если она больше одной правки, он сначала пришлёт черновик плана. Поищите в нём дыры, задайте вопросы, и когда план устраивает, скажите «ок».
5. Изменения видно во вкладке diff этой задачи. Там можно оставить комментарии прямо к строкам (Annotate AI Diff), и агент их учтёт.
6. Когда работа принята, скажите «закрой сессию». Агент закоммитит, оставит итог в задаче и запушит ветку. Слить ветку в основную и убрать отработавшую копию можно в Orca или попросить об этом агента.

Параллельная работа это то же самое ещё раз: нажмите **+** для второй задачи, и у неё будут свои копия и агент. Вкладку задачи можно перетащить к краю окна, чтобы видеть двух агентов рядом.

## Как жить дальше

Ежедневный ритм описан в README в разделе «Как этим жить»: начало работы, вспомнить прошлое, поправить агента, закрыть сессию, раз в неделю разобрать беклог. Как в Orca передавать задачи между агентами и на какие грабли там уже наступали, рассказывает [гайд по Orca](orca.md).

## Если что-то не так

- **Команда не найдена после установки.** Закройте и откройте терминал заново. Если не помогло, перезапустите Orca: её терминалы берут список путей при старте.
- **Агент в новой задаче не реагирует на текст.** Скорее всего, на экране висит вопрос о доверии к папке. Ответьте на него, потом повторите просьбу.
- **`orca status` не отвечает.** Проверьте, что Orca запущена и что в Settings → General включена Orca CLI. На Linux пользуйтесь `orca-ide`.
- **Агент сделал не то.** Скажите прямо, что не так. Он запишет урок, и следующая сессия его прочитает.
- **Непонятно, что происходит.** Спросите агента: «где мы сейчас и что дальше?» Он обязан ответить простыми словами.
