# ADR-0002. Один репозиторий штаба, один канон правил, доставка ссылками

Дата: 2026-09-28. Статус: принято.

## Контекст

У владельца несколько агентов, и каждый ищет свои инструкции в своём месте: Claude Code в `~/.claude/CLAUDE.md`, Codex в `~/.codex/AGENTS.md`, другие агенты в своих каталогах. Если держать копию правил у каждого, копии расходятся за неделю, и никто не знает, какая из них действующая. Скиллы устроены так же: у каждого агента свой каталог.

## Решение

Всё общее живёт в одном репозитории штаба `~/HQ`: доктрина, правила штаба, реестр, уроки, скиллы и детали памяти. Каноном правил для всех агентов служит один файл `~/HQ/doctrine/AGENTS.md`. Агенты получают его не копией, а ссылкой: символической ссылкой на файл или строкой импорта `@~/HQ/doctrine/AGENTS.md`, если агент умеет импорт. Скиллы подключаются так же, ссылкой на каталог `~/HQ/skills/<имя>`.

Правило меняется в одном месте и сразу доезжает до всех агентов. История правил лежит в git штаба.

## Последствия

Там, где символические ссылки недоступны (на Windows без режима разработчика), вместо ссылки ставится импорт, если агент его понимает, или копия с пометкой в первой строке, откуда она сделана. Копию надо обновлять после правки канона, и это единственное место, где расхождение возможно.

Доставку правил проверяют живой цитатой, а не наличием файла: агента просят дословно процитировать контрольную фразу из загруженных инструкций, не читая файлов. Агент, который «видит файл», но не может процитировать из него ни строки, правил не получил. Процедура проверки описана в `SETUP.md`.
