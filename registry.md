# Реестр проектов

Здесь одна строка на проект: где он лежит, где его репозиторий и в каком он состоянии. Это единственный рукописный список проектов штаба. Живое состояние работы сюда не пишется, оно живёт в тикетах и коммитах; здесь только справочные поля, которые нужны агенту, чтобы найти проект.

`slug` совпадает с лейблом `project:<slug>` у тикетов проекта и с именем файла уроков `lessons/projects/<slug>.md`. Статус один из трёх: `active` (идёт работа), `paused` (отложен, но вернёмся), `archived` (закрыт).
